		##Metrics comparison
		
		
			| Metric | Main Focus                                             | Limitation                     |
			| ------ | ------------------------------------------------------ | ------------------------------ |
			
			| Hits@K | Did we retrieve at least one relevant result?          | Ignores ordering quality       |
			|
			| MRR    | How early is the first relevant result?                | Ignores later relevant results |
			|
			| MAP    | Are relevant results consistently ranked near the top? | Usually binary relevance       |
			|
			| NDCG   | How well is the entire list ordered by relevance?      | More complex to interpret      |
